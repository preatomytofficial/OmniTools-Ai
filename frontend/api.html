All downloaded scripts can be executed directly from your terminal:

# 2. Extract 320kbps MP3 from video:
python video_mp3.py -i clip.mp4 -o song.mp3 -b 320k

# 3. Trim a video:
python video_trim.py -i footage.mp4 -o cut.mp4 -s 5.0 -e 15.0
